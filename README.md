# Fleet Management: SQL Server Database & Analytics

A database project for tracking a vehicle fleet, trips, fuel consumption and maintenance, built with **SQL Server (T-SQL)**. The goal is to cover the full path from database design to reporting.

## Why this project
I work in logistics and heavy transport, so the data in this project reflects real-world problems: fuel consumption per driver, vehicle utilization and maintenance costs.

## What the project includes
- Relational database design (normalization, primary and foreign keys)
- T-SQL queries: JOINs, aggregations, window functions
- Stored procedures, indexes, backups and roles (DBA side)
- Power BI dashboard (planned)
- Python scripts for data import and processing (planned)
